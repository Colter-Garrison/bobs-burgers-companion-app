## 🛠 Built with

- **React Native** + **Expo** — cross-platform (iOS / Android / Web)
- **TypeScript**
- **NativeWind** — styling
- **Node.js / Express** + **PostgreSQL** — backend for profiles & favorites
- **Jest** + **React Native Testing Library** + **Playwright** — testing
- **GitHub Actions** — CI
